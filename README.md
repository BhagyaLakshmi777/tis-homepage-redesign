# Tulas International School (TIS) - Homepage Redesign

A modern, animated redesign of the Tulas International School homepage focusing on high conversion, fluid animations, and mobile responsiveness.

## 🚀 Live Demo
- **Live URL: [https://tis-homepage-redesign-nu-three.vercel.app/]
- **Repository: [https://github.com/BhagyaLakshmi777/tis-homepage-redesign.git]

## 🛠️ Tech Stack
- **Framework: React.js
- **Styling: CSS
- **Animations: React State/CSS
- **Deployment: Vercel

## ✨ Standout Features Implemented
1. ** Custom Cursor: When the cursor is on the text, it becomes hand. For this, I used Hover Effect.
2. **  Animated Menu Switcher: I used state variable "isMenuOpen". Initially it is false. When the user clicks on Menu button, it sets to true. Then,close button is displayed and vice versa.

## 📦 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/BhagyaLakshmi777/tis-homepage-redesign.git]
   cd tis-homepage-redesign
```

1. **Install dependencies:**Bash
    
    ```
    npm install
   
    ```
    
2. **Run the development server:**Bash
    
    ```
    npm run dev
   
    ```
    
3. Open http://localhost:5173 in your browser.
